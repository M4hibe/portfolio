Web App Multilingual

A multilingual framework for making AI-generated writing read naturally again, now at v4.0.0 with a universal language layer. I turned the underlying skill into a functional web app so others could clean up AI-assisted drafts in more than one language.

AH

Mahibe Car

Brand Strategy Logo Design

A brand strategy exercise for a car rental company, working through several logo concepts before settling on an abstract mark with a concealed "M". The direction favors a shape that reads clean at small sizes, a real constraint for anything that ends up on a license plate frame or a phone icon.
