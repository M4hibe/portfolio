Selected work

A few things I've built recently.

Monster Mode

UI Design Brand Identity Fitness App

A UI concept for a high-intensity fitness tracking web app. Bold condensed type, near-black canvas, a glowing cyan call-to-action built for a gym floor rather than an office screen. Covers create account, dashboard, sign in and email verification.

Iron Beast

UI Design Mobile App Fitness App

A mobile-first spinoff of the same fitness concept, pushed grittier: a full-bleed training photo, a coral "unleash" call-to-action, and a dashboard built around daily intensity and active missions instead of generic stats.

Monster Trak

UI Design Mobile App Onboarding

A third pass at the same brief, leaning tactical: "status: offline" system language, a stamped logotype, and copy that treats signing up like initializing a protocol rather than filling out a form.

KooraScore

UI Design Sports Booking Mobile App

A concept for a football pitch booking platform: browse venues, check amenities and reviews, pick a date and time slot, and book a pitch, plus a player profile screen with season stats. Dark green canvas and clean cards, built for a Moroccan football crowd who wants to book a pitch as fast as they'd check a score.

Atlas Fleet

React Product Build

A car rental management web app built in React, covering the full operational loop: vehicle management, bookings, customer records and payments. The admin dashboard adds interactive analytics charts, Excel export and custom date-range filtering, so a rental team can see fleet performance without opening a spreadsheet.

AF

Currently in active development. I evaluated the Astro framework early on but moved to a full React setup once it became clear the app's interactivity needs, live filtering, charts and dashboard state, went beyond what a content-first framework was built for.

AI Writing Humanizer

Web App Multilingual

A multilingual framework for making AI-generated writing read naturally again, now at version 4.0.0 with a universal language layer. I turned the underlying skill into a functional web app and shared it so others could clean up AI-assisted drafts in more than one language.

AH

Built from a set of writing rules first, then generalized into a framework that adapts to a given language's grammar and rhetorical habits instead of relying on fixed find-and-replace patterns.

Rental Car

Brand Strategy Logo Design

A brand strategy exercise for a car rental company, working through several logo concepts before settling on an abstract mark with a concealed "M". The direction favors a shape that reads clean at small sizes, a real constraint for anything that ends up on a license plate frame or a phone icon.
